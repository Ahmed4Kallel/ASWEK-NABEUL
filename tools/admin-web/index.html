Flux de publication

        
    
          
  1. 1. Vous modifiez les surcharges dans l'onglet Produits.
    2. 
          
  2. 2. Les surcharges sont enregistrées dans data/admin/overrides.json (fichier source, versionné).
    3. 
          
  3. 3. « Compiler les surcharges » produit data/ai/overrides-applied.json, seul fichier lu par le site public.
    4. 
          
  4. 4. Déployez data/ai/overrides-applied.json (et le sitemap si régénéré) sur l'hébergement.
    5. 
          
  5. 5. Aucune modification n'est visible en ligne tant que l'étape 4 n'est pas faite.
    6. 
        

        
Ce qui est publié automatiquement

        
    
          
  • Meta title, meta description, H1, alt principal, mots-clés d'un produit.
    • 
          
  • Synonymes FR / AR / EN ajoutés à l'index de recherche.
    • 
          
  • Description produit uniquement si son statut est validé.
    • 
        

        
Ce qui n'est jamais publié

        
    
          
  • Les notes internes de validation.
    • 
          
  • Les descriptions en brouillon ou rejetées (elles restent visibles uniquement dans l'admin).
    • 
          
  • Les surcharges dont le slug n'existe pas (l'audit les signale).
